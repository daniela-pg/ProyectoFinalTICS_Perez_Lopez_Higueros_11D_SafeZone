01 — EL PROBLEMA

La seguridad también puede prevenirse con tecnología

En espacios recreativos existen áreas que, por seguridad, deben permanecer restringidas para los visitantes. Detectar oportunamente el ingreso a estas zonas puede ayudar a prevenir situaciones de riesgo.

01

Áreas restringidas

Existen zonas donde el acceso de visitantes no está permitido por motivos de seguridad.

02

Supervisión constante

El monitoreo manual puede dificultarse cuando existen múltiples espacios que supervisar.

03

Respuesta rápida

Una alerta inmediata permite que el personal pueda reaccionar con mayor rapidez.

02 — NUESTRA SOLUCIÓN

Detectar antes. Actuar mejor.

IRTRA SafeZone es una propuesta tecnológica que utiliza sensores y un sistema programado con Arduino para detectar la presencia de personas en zonas previamente definidas como restringidas.

Cuando el sistema identifica una presencia en una zona restringida, genera una alerta para facilitar la atención del personal encargado.

03 — ¿CÓMO FUNCIONA?

Del movimiento a la alerta

Nuestro sistema trabaja mediante un proceso sencillo que permite detectar y responder ante una situación dentro de una zona restringida.

01

Detectar

El sensor identifica movimiento o presencia dentro del área monitoreada.

02

Procesar

Arduino recibe la señal del sensor y procesa la información obtenida.

03

Alertar

Si se detecta una situación no permitida, el sistema genera una alerta de sonido y una luz roja.

04

Actuar

El personal puede verificar la situación y tomar las medidas correspondientes y desactivarlo manualmente luego de atender el problema.
